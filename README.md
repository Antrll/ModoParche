# Parchemos 🇨🇴
> Tu ciudad. Tu gente. Tu parche.

Plataforma local en Villavicencio para descubrir planes, crear parches espontáneos y conectar personas con intereses y presupuestos similares.

## 🚀 ¿Qué problema resolvemos?
Eliminamos la fricción social de coordinar planes en grupos de chat y respondemos a la pregunta: *"Tengo tiempo libre y presupuesto, ¿qué hay para hacer ahora?"*

## 🛠️ Características del MVP
- **Explorador de Parches:** Filtra por categorías (Deporte, Comida, Gaming, Estudio).
- **Sistema de Intención:** Define qué quieres hacer, cuánto quieres gastar y busca coincidencias cercanas.
- **Open the Parche:** Funcionalidad para armar planes públicos abiertos a la comunidad.
- **Mapa de Actividad:** Visualiza los parches activos en la ciudad.
